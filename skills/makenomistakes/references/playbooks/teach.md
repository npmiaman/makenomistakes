# teach

**Probe:** What does the user want to be able to *do* with this, and why? That mission grounds every lesson.

**Tier:** Q — the workspace files are the product; no production code changes.

**Moves** — follow the [`teach` procedure](../procedures/teach/PROCEDURE.md): treat the current directory as a stateful teaching workspace — `MISSION.md`, `RESOURCES.md`, `./lessons/*.html` (one tightly-scoped self-contained lesson each), `./reference/*.html`, `./learning-records/NNNN-*.md`, `NOTES.md`. Ground teaching in high-trust resources before parametric knowledge; build storage strength with retrieval practice, spacing and interleaving; pitch each lesson at the edge of what the learning records show.

**Traps:** lecturing instead of practice · fluency mistaken for mastery · lessons untied to the mission.

**Proof:** the lesson file exists and opens; a learning record captures what was learned and what to revisit.
